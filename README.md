# Claude Code 套餐对比：Pro、Max 5x、Max 20x 与 API 的价格和限额差在哪，国内又怎么付费订阅

搜"Claude Code 套餐对比"的人，多数不是想了解它是什么，而是已经在用、或者准备开始用，卡在一个很具体的问题上：我该买 $20 那档，还是直接上 $100？

先说一个容易被忽略的前提：Claude Code 没有单独的产品页和单独的价格表。它被打包进了 Claude 的订阅体系里，你买的是 Claude 的档位，Claude Code 只是其中一项权益。所以要做对比，对象其实是 Claude 的各个付费档。

## Free 档用不了 Claude Code，最低门槛是 $20

Claude 的免费计划不含 Claude Code，也不含部分新模型，这一点在多份公开资料里一致。想用终端里的那个 `claude` 命令，最低要从 Pro 开始。

所以真正的选择题只有三个价位段：$20、$100、$200，再加上一条完全不同的路线——按量计费的 API。

## 各档位的硬数据

| 档位 | 价格 | 计费方式 | Claude Code | 说明 |
| --- | --- | --- | --- | --- |
| Free | $0 | — | 不含 | 仅网页/App 基础使用 |
| Pro | $20/月；年付折算 $17/月，一次性支付 $200 | 月付或年付 | 包含 | 单账号个人使用 |
| Max 5x | $100/月 | 月付 | 包含 | 用量约为 Pro 的 5 倍 |
| Max 20x | $200/月 | 月付 | 包含 | 用量约为 Pro 的 20 倍 |
| Team | 按席位计费，标准席位约 $20–30/席/月，高级席位显著更高 | 年付或月付 | 包含 | 至少 2 席起 |
| Enterprise | 约 $20/席，另按标准 API 价格结算实际用量 | 合约 | 包含 | 面向组织 |

Max 两档在官网上的表述是"5–20 倍于 Pro 的使用量"，功能层面没有差别，Opus 和 Sonnet 都能用，差别只在额度。Team 的席位价格不同来源给出的数字不完全一致，年付和月付也有差价，具体以官方价格页为准。Pro 的年付是把 $200 一次性付掉，比按月付一年省 $40。

## 限额是两层，不是一层

这是 Claude Code 定价里最容易被误解的地方。付费档位同时受两套限制约束：

1. **5 小时滚动窗口**：从你发出第一条消息开始算，5 小时为一个周期，窗口内可用的量用完就得等。
2. **每周额度**：7 天内还有一个总量上限，并且这个上限不只算 Claude Code 的消耗。

Max 的"5x / 20x"指的是第一层的倍率。问题在于，真正让开发者难受的通常是第二层。2026 年就有一起针对此事的集体诉讼，原告是一位每月付 $200 的 Max 20x 用户，他称实际拿到的用量大约只有 Pro 的 6 到 8 倍，而不是 20 倍。他引用的依据是 Anthropic 在 2025 年 7 月发给订阅用户的邮件，其中给出的每周参考量大致是：

- Pro（$20/月）：每周约 40–80 小时 Sonnet
- Max 5x（$100/月）：每周约 140–280 小时 Sonnet，外加 15–35 小时 Opus
- Max 20x（$200/月）：每周约 240–480 小时 Sonnet，外加 24–40 小时 Opus

按 Sonnet 那一列算，20x 只比 Pro 多 6 倍，而 20x 比 5x 多了大约不到 2 倍。Anthropic 从未公开绝对 token 数，只给相对倍率。

还有一个细节：Claude 网页/App 的聊天和 Claude Code 共用同一个额度池。白天在网页里让 Claude 读几份长文档，晚上终端里的额度就少了。在 Claude Code 里敲 `/usage` 能看到当前窗口和周额度的百分比，`/status` 也能查。

另外，如果你环境变量里设了 `ANTHROPIC_API_KEY`，Claude Code 会把账单走 API，而不是消耗订阅额度。自己付了钱却发现还在扣 API，多半是这个原因。

## Pro 够用吗

取决于你怎么用。一周几个晚上改改脚本、让 Claude 解释一段陌生代码，Pro 是性价比最高的一档。它的额度按 5 小时窗口重置，轻度使用基本碰不到天花板。

但如果你把它当成主力工具，一天开五到八次会话，每次二三十轮，Pro 的额度会在一周的中段就绷紧。这种情况下真正的成本不是那 $20，而是任务做到一半被打断、等窗口重置的时间。

## Max 5x 还是 Max 20x

从 $20 跳到 $100，你买的不是更强的模型，是"不被打断"。从 $100 再跳到 $200，逻辑一样，只是门槛更高。

判断标准可以很简单：**如果你一周里只有一两次撞限额，5x 够；如果几乎每个工作日都会撞，而且撞的时候正卡在关键步骤上，20x 才有意义。**

反过来说，如果 5x 的周额度你都很少用完，20x 多出来的那部分就是纯浪费——$100 的差价换成按量付费的 API 额度，能撑很久。

有个额外选项值得知道：订阅档位用满之后，可以开启"用量额度"（usage credits），超出部分按标准 API 价格结算。这是一个不用换档也能临时续命的口子，适合月底冲刺或者偶尔的批量重构。

## API 按量计费：什么情况下反而更便宜

API 走的是 Anthropic Console，和订阅没有关系，信用额度单独充值，按 token 计费。分模型定价，输入和输出价格不同，整体上是这几个逻辑：

- 不定期使用（比如一个月只跑几次批量处理）——API 比订阅划算
- 自动化/CI 里跑 Claude Code——应该用 API，因为它本来就不适合消耗订阅额度
- 每天高强度交互式写代码——订阅更划算，API 在这种用量下很容易超出 $200

实际单价 Anthropic 会随模型版本调整，写死一个数字意义不大，按当时的官方价格页算一下更靠谱。

## 团队场景

Team 按席位卖，最少 2 席，标准席位和高级席位（含更高 Claude Code 额度）价格差得不少。团队的好处是每个人的限额独立，一个同事用完额度不影响你。

Enterprise 的形态不太一样，按席位收费之后再按 API 价格结算实际用量，适合需要统一账单、合规和管理后台的组织。个人开发者基本不用考虑这两档。

## 国内用户的真正卡点不是选哪档，是付款

上面这些价格都以能顺利付款为前提。现实是，国内银行发行的 Visa/Mastercard 在 Anthropic 和 OpenAI 的支付页面上被拒是常态；虚拟卡用一阵子失效也不稀奇。这才催生了代订阅这一类服务。

## 决定之前，这些记录值得看一眼

代订阅不是零风险的事，把它当成"国内付款的补丁"比当成"更便宜的正规渠道"更接近事实。

- 域名信任评分机构 ScamAdviser 给 bewild.ai 的评分是 56/100，Gridinsoft 给的是 68/100，两者都提到域名注册时间短、注册信息被隐私服务遮蔽。
- 黑猫投诉上有一笔 2026 年 4 月的记录：用户花约 210 美元购买一个月期订阅，实际只用半个月就失效，联系客服没有得到回应。该投诉后来由投诉人自行终止。
- 知乎上也有用户反映 Pro 订阅在使用一段时间后回落到免费版。
- 相对正面的案例同样存在。2026 年 8 月，一位博主记录了 Reader 的三月套餐在续费节点失败、另一笔新购订单显示已完成但账号仍是免费版的情况。客服随后回复并处理：续费失败的原因是原支付方式已失效无法完成扣款，平台按比例退回了约 22 美元；那笔未生效的新订单也完成了退款。

把这些放一起看，结论比较清楚：**付款环节是通的，出问题的环节主要在续费和自动扣款**。这类平台依赖一个下游支付方式持续有效，一旦那条链路断了，订单状态和实际订阅状态就会不一致。

所以如果你决定用，有几个操作值得做：买之前确认平台对失败的退款规则；订阅成功后自己去 Claude 的账单页面核对一次状态；如果页面弹出"修复订阅"提示，但你的 Claude 账号本身显示正常，不需要反复重新上传凭据，这一点平台客服也确认过。另外，Claude 本身对中国大陆 IP 有限制，网络环境是自己要解决的问题，跟选哪一档无关。

## 怎么选：一条按用量走的判断

1. **偶尔写代码、主要用聊天**：Pro，$20/月，年付折 $17。
2. **每天用 Claude Code，但每次会话不长**：先买 Pro 试两周，记录一下 `/usage` 的百分比。经常超过 70%，再考虑 5x。
3. **每天多次长会话、经常撞周额度**：Max 5x，$100/月。这一档覆盖了大部分全职开发者。
4. **并行跑多个 Claude Code、或者同时重度使用 Opus**：Max 20x。但要知道周额度层面它比 5x 多不到一倍，别按字面的"4 倍差价换 4 倍额度"来算。
5. **跑自动化、脚本、CI**：走 API，不要用订阅。
6. **付款是唯一障碍**：可以考虑代订阅，把它当支付通道，同时对续费环节留个心眼。

## 常见问题

**$20 的 Pro 能跑 Claude Code 吗？**
能。Pro 是包含 Claude Code 的最低档位，Free 不含。区别只在额度，不在功能。

**Max 20x 真的是 Pro 的 20 倍吗？**
按 Anthropic 的官方说法，20 倍针对的是 5 小时滚动窗口那一层。每周额度的实际倍率要低得多，2026 年那起诉讼的核心争议就在这里。目前法院没有作出实质裁决。

**订阅档位用超了怎么办？**
可以开启用量额度，超出部分按标准 API 价格计费，不用立刻换档。

**代订阅会拿到别人的账号吗？**
按 WildAI 自己的说明，订阅开在你自己的账号上，平台只通过 Session 凭据完成付款，不接触密码。这也是它和"卖共享号"最主要的区别——共享号的账号归属本来就不是你的。

**订阅到期会自动续费吗？**
从公开记录看，这类平台的续费并不总是顺畅，有时候会失败或者需要重新授权。如果你是长期用户，最好在到期前几天主动检查一次账号里的订阅状态，别等到开始写代码才发现额度没了。
